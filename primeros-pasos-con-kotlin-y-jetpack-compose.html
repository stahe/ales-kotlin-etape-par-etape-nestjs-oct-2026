    3.1.1. El proyecto

    El proyecto de ejemplo fue creado por [Android Studio] (plantilla [Empty Activity], véase el capítulo anterior) y luego completado. Un proyecto [Android] es un proyecto [Gradle]: la herramienta que descarga las bibliotecas, compila el código [Kotlin] y genera el archivo [.apk] que se instala en el teléfono. Se describe mediante unos pocos archivos escritos en [Kotlin] (los archivos [.kts], “Kotlin script”).

// app/build.gradle.kts - la configuración del módulo "app": la aplicación
// de los 25 ejemplos. Generado por Android Studio (plantilla "Empty Activity"),
// y luego completado (líneas marcadas "added").
// =========================================================================
plugins {
    // el plugin de Android: compila el código Kotlin (el propio plugin de Android 9
    // incluye el soporte de Kotlin) y produce el archivo .apk
    alias(libs.plugins.android.application)
    // el compilador de Compose: transforma las funciones @Composable
    alias(libs.plugins.kotlin.compose)
    // agregado: el plugin kotlinx.serialization (clases @Serializable)
    alias(libs.plugins.kotlin.serialization)
}

android {
    // el "paquete" base del código (clase R, BuildConfig...)
    namespace = "fr.stahe.examples"
    // la versión de la API de Android usada para COMPILAR
    compileSdk {
        version = release(37)
    }

    defaultConfig {
        // el identificador ÚNICO de la aplicación en el teléfono
        applicationId = "fr.stahe.examples"
        // la versión de Android más antigua aceptada: Android 8.0 (API 26)
        minSdk = 26
        // la versión de Android para la que se ha probado la aplicación
        targetSdk = 37
        versionCode = 1
        versionName = "1.0"
        // agregado: la dirección del servidor JSON (ejemplos 22 a 25), se puede cambiar en
        // tiempo de compilación: gradlew installDebug -Pserver=http://192.168.1.20:8080
        val server = providers.gradleProperty("server").getOrElse("http://localhost:8080")
        buildConfigField("String", "SERVER_URL", "\"$server\"")

        testInstrumentationRunner = "androidx.test.runner.AndroidJUnitRunner"
    }

    buildTypes {
        release {
            optimization {
                enable = false
            }
        }
    }
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_11
        targetCompatibility = JavaVersion.VERSION_11
    }
    buildFeatures {
        compose = true
        // agregado: la clase BuildConfig (BuildConfig.SERVER_URL)
        buildConfig = true
    }
}

    • líneas 52–55: [compose = true] activa [Compose]; [buildConfig = true], la clase [BuildConfig];
    • Líneas 59–88: las bibliotecas de la aplicación ([implementation]), de las pruebas instrumentadas ([androidTestImplementation]) y de la versión de depuración únicamente ([debugImplementation]).

// hereda de ComponentActivity, que el sistema crea cuando se
// inicia la aplicación. Con Jetpack Compose, la actividad casi no hace nada:
// delega su pantalla a funciones @Composable (setContent).
// Una función @Composable DESCRIBE una parte de la pantalla (un texto, un
// botón, una columna...) llamando a otras funciones @Composable:
// forman un ÁRBOL. Compose ejecuta estas funciones para construir
// la pantalla; las EJECUTA DE NUEVO cuando cambia un dato que leen (un "estado"):
// esto es la RECOMPOSICIÓN. Nunca modificamos la pantalla nosotros mismos.

// una función @Composable: su nombre empieza con mayúscula, como una
// clase (es una pieza de interfaz), y no devuelve nada (Unit)
@Composable
fun HomePage() {
    // el ESTADO: variables observadas por Compose. Modificarlas provoca
    // la reejecución (recomposición) de las funciones que las leen.
    // rememberSaveable: el valor se conserva de una ejecución de la función
    // a la siguiente... e incluso cuando Android recrea la actividad (rotación
    // de pantalla, cambio de idioma)
    var counter by rememberSaveable { mutableIntStateOf(0) }
    var time by rememberSaveable { mutableStateOf(currentTime()) }

    // Scaffold: la estructura de una pantalla Material (barra superior, contenido...)
    Scaffold(
        topBar = { TopAppBar(title = { Text("Example 01 - a first application") }) },
    ) { insets ->
        // Column: hijos colocados uno debajo del otro; los insets
        // del Scaffold (el espacio de la barra superior), y luego 16 dp más
        Column(modifier = Modifier.padding(insets).padding(16.dp)) {
            Text(TITLE, style = MaterialTheme.typography.headlineSmall)
            Spacer(Modifier.height(12.dp))
            Text(
                "This screen is built by Jetpack Compose, from the activity " +
                    "Ex01Activity and the function HomePage.",
            )
            Spacer(Modifier.height(8.dp))
            // ${expression} inserta el valor de una expresión en una cadena
            Text("It is written in ${languages.joinToString(", ")} (${languages.size} technologies).")
            Spacer(Modifier.height(16.dp))
            // onClick: la función (aquí una "lambda") que se llama al presionar.
            // Modificamos el ESTADO; Compose actualiza la pantalla
            Button(onClick = {
                counter++
                time = currentTime()
            }) {
                Text("Click me")
            }
            Spacer(Modifier.height(16.dp))
            Text(
                "You clicked $counter times (last click: $time).",
                fontWeight = FontWeight.Bold,
                color = Color(0xFF087EA4),
            )
        }
    }
}

    • líneas 79–80: el ESTADO. [mutableIntStateOf(0)] crea un valor OBSERVADO por [Compose]: cuando cambia, [Compose] vuelve a ejecutar las funciones que lo leen (recomposición). fun price(text: String): Double = text.replace(',', '.').toDoubleOrNull() ?: 0.0

fun totalInclVat(priceExclVat: Double, quantity: Int, vatRate: Double): Double = quantity * priceExclVat * (1 + vatRate / 100)

@Composable
fun CalculatorPage() {
    // el estado: lo que el usuario ha escrito o elegido
    var label by rememberSaveable { mutableStateOf("Pen") }
    var priceText by rememberSaveable { mutableStateOf("2.5") } // el texto del campo, tal como se escribió
    var quantity by rememberSaveable { mutableIntStateOf(1) }
    var vatRate by rememberSaveable { mutableDoubleStateOf(20.0) }
    // el historial de los últimos 5 cambios del total con IVA: una lista
    // NO MODIFICABLE, reemplazada por una nueva lista en cada cambio
    var history by rememberSaveable { mutableStateOf(listOf<String>()) }

    // valores CALCULADOS: simples variables locales, recalculadas en
    // cada ejecución de la función
    val priceExclVat = price(priceText)
    val totalExclVat = quantity * priceExclVat
    val vatAmount = totalExclVat * vatRate / 100
    val inclVat = totalExclVat + vatAmount

    // TODOS los cambios del estado pasan por esta función local:
    // anota el total con IVA antes del cambio, aplica el cambio y
    // completa el historial si el total ha cambiado
    fun change(update: () -> Unit) {
        val old = inclVat
        update()
        // las variables de estado YA tienen su nuevo valor
        val newTotal = totalInclVat(price(priceText), quantity, vatRate)
        if (newTotal != old) {
            history = (listOf("${euros.format(old)} -> ${euros.format(newTotal)}") + history).take(5)
        }
    }

    // el título de la aplicación SIGUE al estado, como todo lo demás
    TaskTitle("Incl. VAT: ${euros.format(inclVat)}")
    val totalStyle = MaterialTheme.typography.titleMedium.copy(fontWeight = FontWeight.Bold)

    ExamplePage("Example 02 - state") {
        Card {
            Column(Modifier.padding(16.dp)) {
                // un campo CONTROLADO: muestra value y llama a onValueChange
                // en cada pulsación de tecla, con el nuevo texto
                OutlinedTextField(
                    value = label,
                    // cambiar el elemento restablece la cantidad a 1: se hace donde
                    // sabemos POR QUÉ cambia el estado
                    onValueChange = { newValue ->
                        change {
                            label = newValue
                            quantity = 1
                        }
                    },
                    label = { Text("Item") },
                    modifier = Modifier.fillMaxWidth(),
                )
                OutlinedTextField(
                    value = priceText,
                    onValueChange = { text -> change { priceText = text } },
                    label = { Text("Unit price excl. VAT") },
                    // el teclado numérico del teléfono
                    keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Decimal),
                    modifier = Modifier.fillMaxWidth(),
                )
                Spacer(Modifier.height(12.dp))
                Row(verticalAlignment = Alignment.CenterVertically) {
                    // weight(1f): el texto ocupa todo el ancho restante
                    Text("Quantity (back to 1 if the item changes)", Modifier.weight(1f))
                    // enabled = false: el botón está deshabilitado
                    IconButton(onClick = { change { quantity-- } }, enabled = quantity > 0) {
                        Icon(Icons.Default.KeyboardArrowDown, contentDescription = "minus")
                    }
                    Text("$quantity", style = totalStyle)
                    IconButton(onClick = { change { quantity++ } }) {
                        Icon(Icons.Default.Add, contentDescription = "plus")
                    }
                }
                Spacer(Modifier.height(8.dp))
                // botones de los cuales solo UNO está seleccionado: la tasa de IVA
                SingleChoiceSegmentedButtonRow(Modifier.fillMaxWidth()) {

@Composable
fun TasksPage() {
    // listas OBSERVADAS por Compose: agregar, eliminar o reemplazar un
    // elemento provoca la recomposición. (remember, y no rememberSaveable:
    // se pierden si se recrea la actividad, cf. ejemplo 20)

    // teclado del teléfono) desde el código
    val focus = remember { FocusRequester() }

    fun trace(message: String) {
        val time = LocalTime.now().format(DateTimeFormatter.ofPattern("HH:mm"))
        log.add(0, "$time $message")
    }

        val label = input.trim()
        if (label.isEmpty()) {
            return
        }
        tasks.add(Task(nextId++, label))
        trace("added \"$label\"")
        input = ""
        // el foco vuelve al campo: se puede escribir la siguiente tarea
        focus.requestFocus()
    }

    fun toggle(task: Task, done: Boolean) {
        // REEMPLAZAMOS la tarea con una copia modificada
        tasks[tasks.indexOf(task)] = task.copy(done = done)
        trace("\"${task.label}\": ${if (done) "done" else "to do"}")
    }

    fun remove(task: Task, how: String) {
        tasks.remove(task)
        trace("removed \"${task.label}\" ($how)")

// "modificarlo", hacemos una copia: profile.copy(lastName = "DUPONT"). La
// función copy la escribe Kotlin para cualquier clase "data"
data class Profile(
    val title: String,
    val firstName: String,
    val lastName: String,
    val age: Int,
    val newsletter: Boolean,
    val email: String,
    val country: String,
    val presentation: String,
) {
    // el valor de un campo, designado por su nombre
    fun value(f: Field): Any = when (f) {
        Field.TITLE -> title
        Field.FIRSTNAME -> firstName
        Field.LASTNAME -> lastName
        Field.AGE -> age
        Field.NEWSLETTER -> newsletter
        Field.EMAIL -> email
        Field.COUNTRY -> country
        Field.PRESENTATION -> presentation
    }

    // una copia en la que UN campo, designado por su nombre, tiene un nuevo valor
    fun withValue(f: Field, v: Any): Profile = when (f) {
        Field.TITLE -> copy(title = v as String)
        Field.FIRSTNAME -> copy(firstName = v as String)
        Field.LASTNAME -> copy(lastName = v as String)
        Field.AGE -> copy(age = v as Int)
        Field.NEWSLETTER -> copy(newsletter = v as Boolean)
        Field.EMAIL -> copy(email = v as String)
        Field.COUNTRY -> copy(country = v as String)
        Field.PRESENTATION -> copy(presentation = v as String)
    }

    // el objeto JSON del perfil: un campo JSON por campo del formulario
    fun toJson(): JsonObject = JsonObject(
        Field.entries.associate { f ->
            val v = value(f)
            f.name.lowercase() to when (v) {
                is Int -> JsonPrimitive(v) // "is": una prueba de tipo; v es entonces un Int
                is Boolean -> JsonPrimitive(v)
                else -> JsonPrimitive(v.toString())
            }
        },
    )
}

// el estado completo: los valores y los campos ya abandonados
data class State(val values: Profile, val touched: Set<Field>)

// las acciones posibles. "sealed": no hay otras que las
// declaradas aquí, el compilador lo sabe
sealed interface ProfileAction {
    data class Update(val field: Field, val value: Any) : ProfileAction
    data class Leave(val field: Field) : ProfileAction
    data object Uppercase : ProfileAction // un objeto único: la acción no tiene datos
    data object Reset : ProfileAction
}

// el reducer: NUNCA modifica el estado recibido, devuelve uno nuevo.
// En cada rama del when, action tiene el tipo de la rama ("smart cast"):
// action.field es accesible para un Update
fun reducer(state: State, action: ProfileAction): State = when (action) {
    is ProfileAction.Update -> state.copy(values = state.values.withValue(action.field, action.value))
    is ProfileAction.Leave -> state.copy(touched = state.touched + action.field)
    ProfileAction.Uppercase -> state.copy(
        values = state.values.copy(firstName = state.values.firstName.uppercase(), lastName = state.values.lastName.uppercase()),
    )
    ProfileAction.Reset -> State(initial, emptySet())
}

// Devuelve, para cada campo con error, su mensaje. buildMap: llenamos
// un Map modificable, la función devuelve un Map NO MODIFICABLE
fun validate(a: Account): Map<Field, String> = buildMap {
    if (a.title !in titles) put(Field.TITLE, "Choose a title from the list.")
    when {
        a.firstName.isBlank() -> put(Field.FIRSTNAME, "The first name is required.")
        a.firstName.length > 20 -> put(Field.FIRSTNAME, "The first name must not exceed 20 characters.")
    }
    when {
        a.lastName.isBlank() -> put(Field.LASTNAME, "The last name is required.")
        a.lastName.length > 20 -> put(Field.LASTNAME, "The last name must not exceed 20 characters.")
    }
    when {
        a.login.isEmpty() -> put(Field.LOGIN, "The login is required.")
        !loginFormat.matches(a.login) -> put(Field.LOGIN, "Unaccented lower-case letters, digits, dot, hyphen, underscore.")
    }
    when {
        a.password.isEmpty() -> put(Field.PASSWORD, "The password is required.")
        a.password.length < PASSWORD_MIN -> put(Field.PASSWORD, "At least $PASSWORD_MIN characters.")
    }
    // una regla que compara DOS campos
    if (a.confirmation != a.password) put(Field.CONFIRMATION, "The confirmation does not match the password.")
}

package fr.stahe.examples.ex08

import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue

// typealias: un nombre más significativo para un tipo de función
typealias Rule = (String) -> String?

// FÁBRICAS de reglas: cada una devuelve una función de validación
fun required(message: String): Rule = { v -> if (v.isBlank()) message else null }

// una regla que COMPLETA otra: "?:" (el operador Elvis) da el
// resultado de other, si no es null, y en caso contrario el del resto
fun maximum(max: Int, other: Rule): Rule = { v -> other(v) ?: if (v.length > max) "$max characters at most." else null }

class FormField(initialValue: String = "", private val rule: Rule = { null }) {
    // el estado del campo: observado por Compose, modificable solo AQUÍ (private set)
    var value by mutableStateOf(initialValue)
        private set
    var error by mutableStateOf<String?>(null)
        private set

    // ¿ya ha modificado el usuario el campo?
    private var modified = false

    // una pulsación de tecla: el campo se valida a sí mismo en cuanto el usuario lo ha modificado
    fun change(newValue: String) {
        value = newValue
        modified = true
        error = rule(value)
    }

    fun validate(): Boolean {
        error = rule(value)
        return error == null
    }

    // revalidar, solo si el usuario ya ha modificado el campo
    fun revalidate() {
        if (modified) validate()
    }
}

// vararg: cualquier número de campos, Form(firstName, lastName, login...)
class Form(private vararg val fields: FormField) {
    // map primero (TODOS los campos se validan y muestran su error),
    // all después (¿están todos bien?)
    fun validate(): Boolean = fields.map { it.validate() }.all { it }
}

// fechas: formatos "predefinidos" (SHORT, MEDIUM, LONG, FULL), o un patrón
val shortDate: DateTimeFormatter = DateTimeFormatter.ofLocalizedDate(FormatStyle.MEDIUM).withLocale(Locale.US)
val fullDate: DateTimeFormatter = DateTimeFormatter.ofLocalizedDate(FormatStyle.FULL).withLocale(Locale.US)
val timeOnly: DateTimeFormatter = DateTimeFormatter.ofLocalizedTime(FormatStyle.MEDIUM).withLocale(Locale.US)
val frenchDay: DateTimeFormatter = DateTimeFormatter.ofLocalizedDate(FormatStyle.LONG).withLocale(Locale.FRANCE)
val pattern: DateTimeFormatter = DateTimeFormatter.ofPattern("MM/dd/yyyy HH:mm", Locale.US)

// números y montos
val euros: NumberFormat = NumberFormat.getCurrencyInstance(Locale.US).apply { currency = java.util.Currency.getInstance("EUR") }
val integer: NumberFormat = NumberFormat.getNumberInstance(Locale.US)

// apply: configura el objeto recién creado y lo devuelve
val percent: NumberFormat = NumberFormat.getPercentInstance(Locale.US).apply { minimumFractionDigits = 1 }

const val DAY = "2026-10-05" // una fecha en el formato de la API de RdvMedecins
const val PRICE = 1234.5
const val RATE = 0.055
const val NAME = "marie pelissier"
val doctor = mapOf("title" to "Mme", "firstName" to "Marie", "lastName" to "PELISSIER")
val languages = listOf("Kotlin", "Compose", "Dart", "Swift", "SQL")
val slots = listOf(Slot(8, 0, 8, 20), Slot(8, 20, 8, 40), Slot(14, 5, 14, 25))

class Ex09Activity : ComponentActivity() {

@Composable
fun FormattingPage() {
    var now by remember { mutableStateOf(LocalDateTime.now()) }

    // (código mostrado, valor): una fila de la tabla, como un par
    val rows = listOf(
        "shortDate.format(now)" to shortDate.format(now),
        "fullDate.format(now)" to fullDate.format(now),
        "timeOnly.format(now)" to timeOnly.format(now),
        "pattern.format(now)" to pattern.format(now),
        "fullDate.format(LocalDate.parse(DAY))" to fullDate.format(LocalDate.parse(DAY)),
        "frenchDay.format(LocalDate.parse(DAY))" to frenchDay.format(LocalDate.parse(DAY)),
        "now.toString()" to now.toString(),
        "euros.format(PRICE)" to euros.format(PRICE),
        "integer.format(PRICE)" to integer.format(PRICE),
        "\"%.1f\".format(Locale.ROOT, PRICE)" to "%.1f".format(Locale.ROOT, PRICE),
        "percent.format(RATE)" to percent.format(RATE),
        "NAME.uppercase()" to NAME.uppercase(),
        "NAME.capitalized" to NAME.capitalized,
        "\"RDV\".lowercase()" to "RDV".lowercase(),
        "languages.take(3).joinToString(\", \")" to languages.take(3).joinToString(", "),
        "JsonObject(...).toString()" to JsonObject(doctor.mapValues { JsonPrimitive(it.value) }).toString(),
        // dos transformaciones seguidas: el resultado de la primera pasa a la segunda
        "NAME.capitalized.initials" to NAME.capitalized.initials,
    )

    ExamplePage("Example 09 - formatting") {
        // una tabla: la primera columna ocupa el 55 % del ancho (weight)
        Row(Modifier.padding(4.dp)) {
            Text("In the code", Modifier.weight(0.55f), fontWeight = FontWeight.Bold)
            Text("Displayed", Modifier.weight(0.45f), fontWeight = FontWeight.Bold)
        }
        // un par puede "desestructurarse": (code, value)
        for ((code, value) in rows) {
            HorizontalDivider()
            Row(Modifier.padding(4.dp)) {
                Text(code, Modifier.weight(0.55f), fontFamily = FontFamily.Monospace, fontSize = 11.sp, color = Color(0xFFC7254E))
                Text(value, Modifier.weight(0.45f))
            }
        }
        Spacer(Modifier.height(16.dp))
        Text("Going through the entries of a Map", style = MaterialTheme.typography.titleSmall)
        for ((key, value) in doctor) {
            Text("$key = $value")
        }
        Spacer(Modifier.height(16.dp))
        Text("A home-made function: timeRange", style = MaterialTheme.typography.titleSmall)
        for (s in slots) {
            Text("${timeRange(s)} (start: ${timeRange(s, Part.START)})")
        }
        Spacer(Modifier.height(16.dp))
        OutlinedButton(onClick = { now = LocalDateTime.now() }) { Text("Refresh the time") }
    }
}
    • líneas 51–62: los formateadores, creados de una vez por todas fuera de las funciones [@Composable] (crearlos cuesta más que usarlos). [FormatStyle.MEDIUM], [FULL]...: formatos “predefinidos”; [ofPattern]: un patrón; [apply [ ... ]] configura el objeto que acaba de crearse y lo devuelve;
    • líneas 85–103: cada línea de la tabla es un par (código mostrado, valor), generado con [to];
    • línea 113: un par, como una entrada de un [Map], se “desempaqueta”: [for ((code, value) in rows)].

    Nota ["%.1f".format(Locale.ROOT, PRICE)]: sin el idioma “neutro” [Locale.ROOT], [format] usaría el idioma del teléfono y escribiría “1234,5” en francés. Esto es lo que se necesita para la visualización, no para los datos enviados a un servidor.
